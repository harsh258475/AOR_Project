Solution Approach

Leader-follower structure with exact hospital-combination enumeration and follower LP optimization.

Main App Case Study Dataset

1. Bilevel Structure

The upper level selects exactly P hospitals for expansion. Let y_i in {0,1} denote whether hospital i is expanded.

Leader decision:
min   Sum_i c_i y_i
subject to
Sum_i y_i = P

The lower level allocates zone demand to hospitals. In the benefit view, each route has benefit b_ij = M - t_ij, where t_ij is travel cost and M = max(i,j) t_ij.

Primal follower:
max   Sum_i Sum_j b_ij q_ij
s.t.  Sum_i q_ij = d_j                                  for all j
      Sum_j q_ij <= cap_i + X y_i                       for all i
      q_ij >= 0

2. Exact Enumeration Strategy

The implemented solver does not use a single mixed-integer reformulation. Instead, it enumerates every hospital subset of size P and solves the follower allocation LP for each subset.

for each S subset of Hospitals with |S| = P:
    solve   min   Sum_i Sum_j t_ij q_ij
    s.t.    Sum_i q_ij = d_j                            for all j
            Sum_j q_ij <= cap_i + X * 1{i in S}         for all i
            q_ij >= 0

The global optimum is the combination S with minimum total cost:

min over S:  Sum_{i in S} c_i + follower_cost(S)

3. Follower LP

For any fixed expansion subset, the lower-level problem is a continuous transportation LP. Only the hospital capacities change across combinations.

min   Sum_i Sum_j t_ij q_ij
s.t.  Sum_i q_ij = d_j                                  for all j
      Sum_j q_ij <= cap_i + X * 1{i in S}               for all i
      q_ij >= 0

This LP is solved exactly for each candidate subset S. Because every subset is evaluated, the final answer is globally optimal over the combinatorial leader decision.

4. Warm Start Interpretation

The provided hospital IDs are treated as an initial candidate combination. They are evaluated first for comparison, but they do not restrict the search.

Initial candidate:
  S0 = {provided hospital IDs}

Global search:
  evaluate all S with |S| = P

If the provided combination is not optimal, enumeration continues until every combination has been checked.
