Solution Approach

Bilevel optimization with dual reformulation and exact enumeration.

1. Bilevel Problem Structure

The problem is formulated as a bilevel optimization model where the leader selects hospitals for expansion, and the follower allocates patients to hospitals. 

min   Σi ci yi
s.t.  Σi yi = P
      yi ∈ {0,1}

2. Primal Follower (Benefit Maximization)

The follower maximizes total patient benefit, where benefit decreases with travel distance. 

max   Σi Σj bij qij

s.t.  Σi qij = dj                      ∀ j
      Σj qij ≤ î + X yi            ∀ i
      qij ≥ 0

Benefit is defined as bij = M − tij, where tij is travel cost.

3. Dual of the Follower Problem

To convert the bilevel problem into a single-level formulation, we derive the dual of the follower LP. Dual variables are introduced for each constraint:

  • πj for demand constraints
  • μi ≥ 0 for capacity constraints
min   Σj dj πj + Σi (î + X yi) μi

s.t.  πj + μi ≥ bij         ∀ i,j
      μi ≥ 0

The dual captures the marginal value of satisfying demand and using capacity.

4. Strong Duality

At optimality, the primal and dual objective values are equal. 

Σi Σj bij qij
=
Σj dj πj + Σi (î + X yi) μi

5. Single-Level Reformulation

The bilevel problem is transformed into a single-level optimization problem by embedding:

  • Primal feasibility constraints
  • Dual feasibility constraints
  • Strong duality condition
min   Σi ci yi

s.t.  primal constraints
      dual constraints
      strong duality condition

This results in a mixed-integer linear programming (MILP) formulation.

6. Problem Simplification

Since benefit is defined as bij = M − tij, maximizing benefit is equivalent to minimizing travel cost. Therefore, the follower problem reduces to a transportation problem: 

min   Σi Σj tij qij

s.t.  Σi qij = dj
      Σj qij ≤ î + X yi
      qij ≥ 0

This eliminates the need to explicitly solve the dual in implementation.

7. Final Equivalent Problem

min over S:
    Σ{i ∈ S} ci + routing_cost(S)

The routing cost is obtained by solving the follower transportation problem.

Exact Strategy

for each subset S with |S| = P:
    solve follower LP
    compute total cost
    update best solution

Summary

The bilevel problem is theoretically converted into a single-level formulation using duality and strong duality. However, due to the structure of the benefit function, the follower simplifies to a transportation model. Therefore, an exact enumeration approach is used to efficiently obtain the global optimum.
